# 设备管理界面 - 客户端与设备删除功能实施计划

## 摘要

为「设备管理」界面（`ClientDeviceView.vue`）的客户端列表和设备列表增加删除功能。后端 API 已存在但缺少级联删除逻辑，前端 API 层已定义但 UI 和 Store 均未消费。

---

## 现状分析

### 后端（falconconsole）

| 文件 | 当前状态 |
|------|----------|
| `controller/PatrolClientController.java` | `/clients/delete` 接口已存在，直接调用 `clientService.removeById(id)`，**未级联删除关联设备** |
| `controller/PatrolClientDeviceController.java` | `/client-devices/delete` 接口已存在，直接调用 `deviceService.removeById(id)` |
| `service/PatrolClientDeviceService.java` | 无 `deleteByClientId` 方法 |
| `service/impl/PatrolClientDeviceServiceImpl.java` | 无按 clientId 批量删除的实现 |

### 前端（frontend）

| 文件 | 当前状态 |
|------|----------|
| `api/client.js` | `deleteClient()` 和 `deleteDevice()` 方法已定义，但**从未被任何模块 import 或调用** |
| `stores/client.js` | 无 `deleteClient` / `deleteDevice` action，import 中未引入删除 API |
| `views/client/ClientDeviceView.vue` | 客户端卡片只有点击选中功能，无删除按钮；设备表格无操作列 |

### 参考模式

- `PatrolSystemController.delete()` 展示了级联删除模式：删除系统前先调 `deleteTerminalsBySystemId()` 清理关联数据。

## 变更方案

### 一、后端：增加级联删除支持

#### 1.1 `PatrolClientDeviceService.java` — 新增接口方法

**文件**: `falconconsole/src/main/java/com/falcon/patrol/service/PatrolClientDeviceService.java`

新增方法签名：

```java
/**
 * 删除指定客户端下的所有设备（级联删除）
 */
int deleteByClientId(String clientId);
```

#### 1.2 `PatrolClientDeviceServiceImpl.java` — 新增实现方法

**文件**: `falconconsole/src/main/java/com/falcon/patrol/service/impl/PatrolClientDeviceServiceImpl.java`

新增实现：

```java
@Override
public int deleteByClientId(String clientId) {
    return baseMapper.delete(Wrappers.lambdaQuery(PatrolClientDevice.class)
            .eq(PatrolClientDevice::getClientId, clientId));
}
```

#### 1.3 `PatrolClientController.java` — 修改 delete 方法增加级联逻辑

**文件**: `falconconsole/src/main/java/com/falcon/patrol/controller/PatrolClientController.java`

- 新增注入 `@Autowired private PatrolClientDeviceService deviceService;`
- 修改 `delete` 方法：先级联删除下属设备，再删除客户端

修改前：
```java
@PostMapping("/delete")
public Result<Boolean> delete(@RequestBody IdRequest req) {
    return Result.success(clientService.removeById(req.getId()));
}
```

修改后：
```java
@PostMapping("/delete")
public Result<Boolean> delete(@RequestBody IdRequest req) {
    // 级联删除该客户端下的所有设备
    deviceService.deleteByClientId(req.getId());
    return Result.success(clientService.removeById(req.getId()));
}
```

### 二、前端 Store：新增删除 Actions

#### 2.1 `stores/client.js` — 新增 deleteClient 和 deleteDevice action

**文件**: `frontend/src/stores/client.js`

- import 中增加 `deleteClient, deleteDevice` 从 `@/api/client`
- 新增 `deleteClient(clientId)` action：调用 API → 成功后将 `currentClient` 置为 null → 刷新客户端列表
- 新增 `deleteDevice(deviceId)` action：调用 API → 成功后重新加载当前客户端设备列表
- 在 `return` 中导出新增的 actions

### 三、前端 UI：增加删除按钮与确认对话框

#### 3.1 `ClientDeviceView.vue` — 模板变更

**文件**: `frontend/src/views/client/ClientDeviceView.vue`

##### 3.1.1 客户端卡片增加删除按钮

在 `client-card-header` 区域内，状态标签旁边增加一个删除图标按钮（`<el-button>` + `Delete` 图标，type="danger"，plain，size="small"，链接样式），点击时阻止事件冒泡（`@click.stop`），触发 `handleDeleteClient(row)`。

##### 3.1.2 设备表格增加操作列

在 `el-table` 最后增加一列 `el-table-column`，label="操作"，width="80"，fixed="right"，内含删除按钮（`<el-button type="danger" link size="small">删除</el-button>`），点击触发 `handleDeleteDevice(row)`。

#### 3.2 `ClientDeviceView.vue` — 脚本变更

- import 中增加 `Delete` 图标（从 `@element-plus/icons-vue`）
- 新增 `handleDeleteClient(row)` 方法：
  - 使用 `ElMessageBox.confirm` 弹出确认对话框（提示："确定删除客户端 {hostname} 吗？该客户端下的所有设备也将被删除。"）
  - 确认后调用 `store.deleteClient(row.id)`，成功后 `ElMessage.success`
  - 捕获取消（catch 中忽略 cancel 错误）
- 新增 `handleDeleteDevice(row)` 方法：
  - 使用 `ElMessageBox.confirm` 弹出确认对话框（提示："确定删除设备 {serial} 吗？"）
  - 确认后调用 `store.deleteDevice(row.id)`，成功后 `ElMessage.success`

## 假设与决策

1. **物理删除**：沿用项目现有的物理删除方式（`removeById`），不引入软删除。
2. **级联删除**：删除客户端时同步删除其下全部设备，遵循 `PatrolSystemController` 的级联删除模式。
3. **不处理上传文件**：删除客户端时不自动清理其关联的上传文件记录（`patrol_client_uploaded_files`），保持变更范围最小。
4. **设备列表不刷新客户端**：删除设备后仅刷新设备列表，不影响左侧客户端列表（客户端数据不变）。

## 验证步骤

- **后端**：`mvn compile`（仅在 `falconconsole` 目录下）确保编译通过
- **前端**：`cd frontend && pnpm build`（或 `vite build`）确保构建通过
- **手工验证**：
  1. 在设备管理页面点击客户端卡片的删除按钮 → 弹出确认框 → 确认后客户端从列表消失，若该客户端处于选中状态则右侧清空
  2. 在设备表格中点击某设备的删除按钮 → 弹出确认框 → 确认后设备从表格消失
  3. 后端确认：删除客户端后该客户端关联的设备记录一并删除
